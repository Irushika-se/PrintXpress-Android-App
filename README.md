# PrintXpress

PrintXpress is an Android application project.

## Getting Started

1. Install Android Studio and a compatible Android SDK.
2. Extract this project.
3. Open the project folder in Android Studio.
4. Allow Gradle to sync and download required dependencies.
5. Select an emulator or connected Android device and run the app.

## Notes

- `local.properties` is intentionally excluded because it contains a machine-specific Android SDK path.
- Build outputs and IDE-specific files are excluded from version control.
- Do not commit passwords, API keys, signing keys, or other private credentials.
